# 이브레 디지털조판시스템

InDesign 18.5 이상과 UXP Developer Tool이 필요합니다. Developer Tool에서 이 폴더의 manifest.json을 추가한 뒤 Load를 누르면 InDesign의 플러그인 메뉴에서 이브레 디지털조판시스템을 열 수 있습니다.

1. 뉴스룸에서 호수, 발행일, 전체 면수를 등록합니다.
2. 발행 계획을 등록하면 기본 INDD와 미리보기가 각 면에 연결됩니다. 뉴스룸 모니터링 화면에서는 미리보기를 확인할 수 있습니다.
3. InDesign에서 뉴스룸 이메일로 로그인하고 발행 계획의 면 목록에서 열기를 누릅니다. 닫기 전까지 다른 편집자가 해당 면을 열 수 없습니다.
4. 문서를 저장하면 INDD와 JPEG 미리보기가 동기화됩니다. 동기화 상태는 패널 하단에 표시됩니다. 실패하면 같은 문서를 열어 둔 상태에서 면 목록에서 해당 면의 업로드를 누를 수 있습니다. 편집 중에도 이 버튼으로 현재 내용을 저장하고 올릴 수 있습니다. 강판과 강판 해제는 뉴스룸 지면 모니터링에서 합니다.

소스에서 플러그인을 로드할 때는 배포 ZIP의 templates 폴더를 manifest.json 옆에 복사합니다.

문서마다 50MiB까지 저장할 수 있습니다. 외부 링크 이미지와 글꼴은 편집 환경에 따로 준비해야 합니다. 조판 자료는 공개 지면보기 발행과 별개입니다.
