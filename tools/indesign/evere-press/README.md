# 이브레 조판

InDesign 18.5 이상과 UXP Developer Tool이 필요합니다. Developer Tool에서 이 폴더의 manifest.json을 추가한 뒤 Load를 누르면 InDesign의 플러그인 메뉴에서 이브레 조판을 열 수 있습니다.

1. 뉴스룸에서 호수, 발행일, 전체 면수를 등록합니다.
2. 각 면에 해당하는 1페이지 INDD 파일을 등록합니다. 원본 파일과 함께 JPEG를 올리면 초기 미리보기도 표시됩니다.
3. InDesign에서 뉴스룸 이메일로 로그인하고 호와 면을 선택해 엽니다.
4. 문서를 저장하면 INDD와 JPEG 미리보기가 동기화됩니다. 동기화 상태는 패널 하단에 표시됩니다. 실패하면 같은 문서를 열어 둔 상태에서 현재 면 웹에 동기화를 누를 수 있습니다.

문서마다 50MiB까지 저장할 수 있습니다. 외부 링크 이미지와 글꼴은 편집 환경에 따로 준비해야 합니다. 조판 자료는 공개 지면보기 발행과 별개입니다.
